# Ruby Scripts and Utilities

This repo contains a collection of small Ruby scripts written for learning, experimentation, and solving focused problems. Some scripts are simple coding exercises, while others are practical utilities.

These are intentionally lightweight and self-contained.

---

## Contents

### Security and Crypto Practice
- **CaesarCipher.rb**  
  Implements a basic Caesar cipher.

- **pig_latin.rb**  
  Translates input text into Pig Latin.

---

### Utilities
- **csr_gen.rb**  
  Generates a certificate signing request (CSR).

- **extract.rb**  
  Extracts data from most known archives like zip, tar, etc.

- **toc.rb**  
  Generates a table of contents.

- **hosting-cost-report.rb**  
  Generates or analyzes hosting cost data.

---

### Coding Exercises
- **fibonacci_numbers.rb**  
  Generates Fibonacci numbers.

- **largest_prime_factor.rb**  
  Calculates the largest prime factor of a number.

- **leapyear.rb**  
  Determines whether a given year is a leap year.

---

## Usage

Most scripts can be run directly with Ruby:

```bash
ruby script_name.rb
